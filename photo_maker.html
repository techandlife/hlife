We can generate photo by using Canvas object.


The Dart code:

void paint(Canvas canvas, Size size) { Size mySize = Size(400, 400); final Paint paintRect = Paint()..color = Colors.lightBlue; final Rect rect = Offset.zero & mySize; canvas.drawRect(rect, paintRect); final paragraphBuilder = ui.ParagraphBuilder(ParagraphStyle()) ..addText("this is a photo maker demo."); final constraints = ui.ParagraphConstraints(width: mySize.width); final paragraph = paragraphBuilder.build(); paragraph.layout(constraints); canvas.drawParagraph(paragraph, Offset.zero); }
