Sometimes we need to detect the scrollbar event.


The Dart code:

@override void initState() { super.initState(); _sCtrl = ScrollController(); _sCtrl.addListener(scroll); } void scroll() { print("scrolling."); } @override Widget build(BuildContext context) { return Scaffold( appBar: AppBar(title: Text("Scrollbar demo")), body: Scrollbar( child: ListView.builder( itemCount: 99, itemBuilder: (context, index) { return Text("item $index"); }, controller: _sCtrl, ), ), ); }
